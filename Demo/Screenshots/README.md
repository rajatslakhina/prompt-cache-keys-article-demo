# Screenshots

No Simulator screenshot is committed for v1.0.0.

The build pipeline that produced this repo runs unattended, and its Xcode/Simulator
access could not be approved in that run, so `Demo.xcodeproj` was not launched on a
Simulator before publishing. The library was verified with `swift build` and
`swift test` (30 tests) on Linux; the project file was checked for structural
validity by hand. If you run the demo, a screenshot of the "Prompt Cache Ledger"
screen dropped into this folder would be a welcome pull request.
